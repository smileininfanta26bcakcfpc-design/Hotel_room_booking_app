StayVista – Hotel Room Booking Application
Project Overview
StayVista is a hotel room booking mobile application designed to provide users with a simple, convenient, and user-friendly hotel reservation experience. The application allows users to explore hotels, view room details, enter guest information, select payment methods, and confirm their bookings.
The UI is designed in Figma with a premium visual style using dark green, golden accents, and attractive hotel imagery.
Objectives
Provide an easy-to-use hotel booking interface.
Help users discover hotels and explore available rooms.
Display hotel information, room details, prices, and ratings.
Allow users to enter check-in, check-out, and guest details.
Provide multiple payment options.
Display a booking confirmation screen after the booking process.
